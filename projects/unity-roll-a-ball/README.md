# Unity Roll-a-Ball

A Unity physics game in which the player moves and jumps, collects rotating items, tracks a score, and completes the game after reaching the target count.

## Main Features

- Rigidbody-based player movement and jumping
- Camera tracking
- Pickup rotation and collection
- Score and victory UI
- Collision feedback and knockback
- Coroutine-based random item spawning

## Open the Project

1. Install Unity `2020.3.29f1`.
2. Open this directory from Unity Hub.
3. Open `Assets/new_Scenes/New_Scenes.unity`.
4. Enter Play mode.
